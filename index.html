          Language reference
          
Live editing

          

            
Ctrl+Enter
Run, or update the running code.

            
Ctrl+.
Stop.

            
Ctrl+Z · Ctrl+Shift+Z
Undo and redo every change: typing, scrubbing, the key slider, mute, imports. On a Mac, Cmd.

            
Double-click a number
Opens a slider under it; drag and the sound follows. Edit the two ends to change the range. ←/→ fine-tune, Esc or Enter closes. While it is open, Backspace deletes the number and typing replaces it, as if it were selected. Ctrl/Cmd+click works too.

            
Suggestions
While you type, a list of what fits comes up: modifiers after a dot, track types, wave names, modes, functions and your own variables. ↑/↓ choose, Tab or Enter insert, Esc closes. A misspelled name in an error message comes with "Did you mean …?".

            
Alt + wheel
Over a number: one step per notch. Shift for ×10.

            
Alt + ↑ / ↓
With the cursor in a number: change the digit just left of the cursor. 6|50 changes the hundreds.

            
Ctrl+S
Save the song in this browser under the name in the console title (click it to rename); saving again with the same name updates it. Saved songs are in STAGE, under "Saved in this browser"; × deletes the open one. Your code is also kept as you type, so reloading picks up where you left off. TXT downloads a .txt; OPEN loads one back. On a Mac, Cmd+S.

            
Alt+M · Alt+S
Mute or solo the track under the cursor; press again to undo. Select several lines to mute or solo every track they touch at once: if any lacks the flag they all get it, otherwise they all lose it. On a Mac, Option. Mute and solo combine: with any solo on, only soloed tracks play, and a muted track stays silent even when soloed.

          

          
Statements

          

            
bpm 135
Tempo. One cycle = one bar of 4 beats.

            
key d aeolian
Global key. The slider and mode buttons rewrite this line; editing it and running moves the slider.

            
let x = expr
Variable, recomputed every cycle.

            
t name type: expr .mod
A voice. t is short for track, and the name can be left out: t kick: [1 1 1 1] (a second kick is kick2). Patterns fill one cycle. Add modifiers with a dot: .gain .4 .lpf 800, or .lpf(800).

            
open [ on many lines ]
A line with an open bracket continues on the next lines.

            
.voice c4 on its own line
A line that starts with a dot adds modifiers to the track above it, so a long track can put one modifier per line.

          

          
Track types

          

            
deg
Scale degrees, 0 = tonic, 7 = octave up, −1 = one step below. b or # in front lowers or raises that degree a semitone, counted from 0 like every other number: in C major b2 = Eb, #3 = F#, b6 = Bb, so [0 b2 4 b6] is C Eb G Bb. Only in a deg track: in a note track b2 is the note B2.

            
chord
Chords. Numbers 1–7 stack thirds in the mode (.seven adds the 7th); Roman numerals give an exact chord; {d4 f4 a4 c5} plays those notes; {0 2 4 6} plays those scale degrees. Bass follows the lowest note, arp the notes from low to high.

            
bass
Semitones above the root of the current chord: [0 ~ ~ 12] is an octave bass.

            
arp
Tones of the current chord: 0 root, 1 third, 2 fifth, 3 seventh; higher numbers go up an octave.

            
note
Absolute notes c4 eb4 f#5, played exactly as written. When linked, the slider rewrites the note names: scale notes keep their degree, raised or lowered notes stay raised or lowered.

            
kick snare clap rim
Drums. Values are velocity, ~ is silence.

            
hat ohat crash
Closed hat, open hat, crash cymbal.

          

          
Chord symbols

          

            
I  vi
Upper case is major, lower case is minor, built on that degree of the key.

            
i7 V7 IVmaj7
Minor 7th, dominant 7th, major 7th.

            
iim7b5 vii°7
Half-diminished, diminished 7th. Also dim, aug, sus2, sus4, 7sus4, 9sus4, 6, m6, 6/9, 9, m9, maj9, add9, add11, 11, m11, 13, m13, maj13, mmaj7, 7b5, 7#5, 7b9, 7#9, 7#11, 7b13, maj7#11.

            
5:7b9 1:9 2m7b5
A numbered chord with a suffix: the root is that degree of the key, the suffix sets the chord. A suffix that starts with a digit needs the colon (5:7b9, 4:6/9); one that starts with a letter can follow directly (2m7b5, 1add9) or take the colon too. A plain number still stacks thirds in the mode.

            
V7/iv
Secondary chord: V7 of the iv chord.

            
bVII #iv
Lower or raise the root a semitone.

            
C Dm7 Bbmaj7 F#m
Chord names with a fixed root, upper-case letter first, same suffixes as above: [Dm7 C Bbmaj7 Fmaj7] works as written. The track decides what C7 means: in a chord track (and anything it plays, such as a let or .of) it is a C7 chord; in a note track it is the note C7. Inside { } it is always a note.

          

          
Patterns

          

            
[a b c]
Split the time span into steps.

            
<a b>
Pick one per cycle, in turn.

            
~   a!3
Rest. Repeat a step 3 times.

            
[c4 _ _ e4]
_ holds the step before it: c4 lasts three steps.

            
{c4 e4 g4}
Play together, as one chord.

            
+ - * / %
Math, applied to every step. Inside [ ] use ( ).

            
t
Current cycle (bar) number.

          

          
Functions

          

            
slow(p, n)
Spread a list over n bars. slow([a b c d], 2) plays two per bar.

            
sect(n, a, b, …)
Switch section every n bars: intro, verse, drop.

            
range(a, b)
Steps a through b.

            
euclid(k, n, r)
k hits spread over n steps.

            
rev(p) rot(p, n)
Reverse. Rotate by n steps.

            
fast(p, n)
Speed: 2 plays p twice as fast, 1/2 half as fast (the same as slow(p, 2)).

            
pick(p, i)
Step i of p, wrapping.

            
every(n, a, b)
a on every nth cycle, else b.

            
rand(a, b) choose(…)
Random integer, random choice.

            
floor abs sin min max len
Math helpers.

          

          
Modifiers

          

            
.of chords
Which chord track a bass or arp follows (or a chord pattern). Defaults to the first chord track.

            
.voice c4
Keep chord tones within a fifth of c4, so chords move smoothly. On bass and arp it sets where the root sits.

            
.duck .6
Sidechain pump: dips the track on every kick by this much.

            
.room .4
Reverb: how much of the track goes into the shared hall, 0–1.

            
.delay .3
Echo on a dotted eighth, locked to the bpm, 0–1.

            
.chorus .5
Chorus: a wider, thicker sound, 0–1.

            
.dist .5
Distortion: soft clipping, 0–1. Higher is dirtier.

            
.phaser .5
Phaser: a slow sweeping whoosh, 0–1.

            
.crush 6
8-bit crusher: bit depth 1–16, lower is grittier and more lo-fi.

            
.oct n
Octave (4 = middle C).

            
.wave sine / saw / square / tri
Basic oscillators.

            
.wave super / pulse / pluck / fm / organ
super is a supersaw, seven detuned saws, wide and thick. pulse is a thin, nasal square. pluck has a bright snap that dies away fast. fm is a bell-like tone. organ stacks a few harmonics.

            
.gain .lpf .len .pan
Level, low-pass Hz, note length 0–1, pan −1…1. Each takes an expression.

            
.hpf 300
High-pass Hz: cuts everything below it. Thins out a pad, clears room for the bass. Works on drums too, and takes an expression: .hpf 200 + 800 * sin(t).

            
.fast n
Track speed: .fast 2 plays the pattern twice a bar, .fast 1/2 stretches it over 2 bars, .fast 1/4 over 4.

            
.on [0 1 1 0]
Play only where the list says 1. With a let called sec, the list has one entry per section and sec picks it; without one, one entry per bar. Any expression works: .on t % 2 plays every other bar.

            
.seven
Numbered chords add the 7th.

            
.mute
Silence this track. Alt+M adds or removes .mute on the track under the cursor.

            
.solo
Hear only soloed tracks. Alt+S adds or removes .solo.

            
.link d dorian
Follows the global key (checked).

            
.key e phrygian
Keeps its own key (unchecked).
